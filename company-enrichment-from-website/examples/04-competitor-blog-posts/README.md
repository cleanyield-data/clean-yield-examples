# Get the latest blog posts of competitor websites

Get the latest posts (title, URL, ISO date) from each company's RSS/Atom feed or blog page, newest first. Useful to track what competitors publish or to personalize outreach with a recent post.

- Actor: [Company Enrichment from Website](https://apify.com/cleanyield/company-enrichment-from-website)
- Real run: 3 results in 1.3 s (refreshed 2026-11-06)
- `input.json`: paste it in the Actor input (JSON tab) or send it to the API.
- `output-sample.json`: the first 5 results of that run.

**Limitations:** Needs a public feed or a blog page with dated articles. Sites without a blog return no posts (and are charged only if other data was found). Only the newest maxPosts posts are returned.
