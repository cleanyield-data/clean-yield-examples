# SECOP II tenders for cleaning and security services in Colombia

Open competitive processes (mínima cuantía, selección abreviada, licitación pública) for cleaning (aseo) and private security (vigilancia) services published on SECOP II in the last 10 days, from the official datos.gov.co open data. Direct contracts are excluded.

- Actor: [Latin America Public Tenders](https://apify.com/cleanyield/latam-public-tenders)
- Real run: 10 results in 1.6 s (refreshed 2026-11)
- `input.json`: paste it in the Actor input (JSON tab) or send it to the API.
- `output-sample.json`: the first 5 results of that run.

**Limitations:** SECOP II open data only has dates (no time of day), so closingAt is null and closingDate is set. Data arrives with a 1–4 day delay.
