# IT and software government tenders in Colombia, Brazil and Chile (open, this week)

Every open public tender for software licences, computers and IT services published in the last 5 days in Colombia (SECOP II), Brazil (PNCP) and Chile (Mercado Público), in one normalized format. The ready-made it-software sector matches Spanish and Portuguese keywords in the title and UNSPSC codes of the main category; each country gets a fair share of the results.

- Actor: [Latin America Public Tenders](https://apify.com/cleanyield/latam-public-tenders)
- Real run: 15 results in 31.6 s (refreshed 2026-11)
- `input.json`: paste it in the Actor input (JSON tab) or send it to the API.
- `output-sample.json`: the first 5 results of that run.

**Limitations:** Colombia's open data arrives with a 1–4 day delay, so its newest tenders are a few days old. Run time depends on the government APIs (measured 9–66 s for this input on 2026-11-04).
