# Hazmat carriers in Louisiana

Active carriers flagged as hazardous-materials carriers in Louisiana, largest fleets first, with safety rating, out-of-service status and BIPD insurance on file (hazmat requires $1M–$5M).

- Actor: [FMCSA Carrier Data](https://apify.com/cleanyield/fmcsa-carrier-data)
- Real run: 15 results in 4.1 s (refreshed 2026-11-05)
- `input.json`: paste it in the Actor input (JSON tab) or send it to the API.
- `output-sample.json`: the first 5 results of that run.

**Limitations:** Some very large self-reported fleets are data-entry errors in the FMCSA census; they are flagged with dataQualityFlags = implausibleFleetSize.
