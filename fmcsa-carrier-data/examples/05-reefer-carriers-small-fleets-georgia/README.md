# Refrigerated (reefer) carriers with 5–50 trucks in Georgia

Target small and mid-size reefer fleets: carriers in Georgia that haul refrigerated food and run 5 to 50 power units. Fleet size is counted like SAFER (trucks + buses), not the inflated raw census column.

- Actor: [FMCSA Carrier Data](https://apify.com/cleanyield/fmcsa-carrier-data)
- Real run: 20 results in 4.9 s (refreshed 2026-11-05)
- `input.json`: paste it in the Actor input (JSON tab) or send it to the API.
- `output-sample.json`: the first 5 results of that run.

**Limitations:** Cargo types and fleet size are self-reported by the carrier on its MCS-150 and can be outdated; check mcs150Date.
