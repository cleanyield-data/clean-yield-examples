# Freight brokers with active authority in Illinois

Find property brokers registered in Illinois with an active MC authority, with phone, email, address and broker bond (BMC-84/85) details.

- Actor: [FMCSA Carrier Data](https://apify.com/cleanyield/fmcsa-carrier-data)
- Real run: 20 results in 4.6 s (refreshed 2026-11-05)
- `input.json`: paste it in the Actor input (JSON tab) or send it to the API.
- `output-sample.json`: the first 5 results of that run.

**Limitations:** Entity type comes from the FMCSA registration (a company can be carrier and broker at the same time). Bond details depend on what is filed with FMCSA.
