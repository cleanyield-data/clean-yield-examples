# Internships at tech companies across Greenhouse, Lever and Ashby

Collect internship postings from Ramp, Zoox, Palantir, Datadog, Cloudflare and Robinhood with one filter: employmentTypes internship. The employment type is normalized across ATS (Lever 'Internship', Ashby 'Intern', titles with 'Intern'). 59 internships found.

- Actor: [ATS Jobs Scraper](https://apify.com/cleanyield/ats-jobs-scraper)
- Real run: 59 results in 6.2 s (refreshed 2026-11-05)
- `input.json`: paste it in the Actor input (JSON tab) or send it to the API.
- `output-sample.json`: the first 5 results of that run.

**Limitations:** On Greenhouse the type comes from custom fields or the title; an internship whose title and fields do not say so can be missed.
